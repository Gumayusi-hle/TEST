海康摄像头 OSD 预置工具  使用说明
================================================================

一、这个工具解决什么问题

MATE-X3 移动式主板通过 ONVIF 向摄像头写气体叠加，代码里只认
OsdToken_102 这一条 OSD。

海康摄像头出厂只有两条 OSD（通道名、日期时间），没有 102。
所以主板找不到目标，画面上就不显示气体数据。

本工具在摄像头上预先创建一条 OSD，海康会自动把它命名为
OsdToken_102 —— 正好是主板在找的那个。

不用改固件。


二、使用前必须做的两件事（每台摄像头都要）

1. 打开摄像头的 ONVIF
   Web 登录 → 配置 → 网络 → 高级设置 → 集成协议
   → 勾选「启用 ONVIF」→ 保存

2. 添加一个 ONVIF 用户
   同一页下方「用户列表」→ 添加
   用户名/密码自己定，类型建议选「管理员」
   注意：ONVIF 用户和 Web 管理员是两套账号，不通用

做好这两步，再跑工具。


三、怎么用

双击「部署OSD.bat」，按菜单选：

  1  检查       只读，看看摄像头有没有 102，不改任何东西
  2  单台部署   输入 IP、账号、密码，自动创建
  3  批量部署   把多台设备写进「设备清单.txt」，一次跑完
  4  删除       把 102 删掉，恢复成出厂状态

建议顺序：先「检查」确认连得上 → 再「部署」。


四、会生成什么

每次运行都会在当前目录生成一个 CSV：

  OSD部署记录_20260101_120000.csv

字段：时间、IP、型号、序列号、固件、原OSD数、动作、token、结果、备注

这个 CSV 就是部署台账，客户要「配置清单」时可以直接给。


五、四个必须知道的坑

1. token 必须是 OsdToken_102
   工具建完会回读核对。如果摄像头分配的编号不是 102（比如已经是 103），
   工具会自动删掉并报「需处理」——这种型号需要固件适配，不能靠工具解决。

2. 不要用 OsdToken_100 / 101
   100 是通道名，101 是时间。覆盖了画面上的通道名或时间戳就没了。

3. 位置在左下角
   默认坐标 (-0.85, 0.75)，和通道名、时间不重叠。
   要改位置用命令行：--pos -0.9 0.6

4. 摄像头固件升级后可能丢
   升级完重新跑一次「检查」确认。


六、常用命令（不想用菜单就直接敲）

  检查
    python hik_osd_setup.py --check 192.168.1.100 admin 密码

  单台部署，自定义文字
    python hik_osd_setup.py 192.168.1.100 admin 密码 --text "GAS 0.0%LEL"

  改位置和字号
    python hik_osd_setup.py 192.168.1.100 admin 密码 --pos -0.9 0.6 --font 28

  批量
    python hik_osd_setup.py --file 设备清单.txt

  删除
    python hik_osd_setup.py --remove 192.168.1.100 admin 密码


七、验证部署是否成功

1. 工具显示「新建 OsdToken_102」或「复用 OsdToken_102」= 成功
2. 登录摄像头 Web，配置 → 图像 → 字符叠加，应能看到这条文本
3. 实时画面上应在设置的位置出现占位文字
4. 主板通电运行后，占位文字应被真实气体数据覆盖


八、回滚

删除 102：
  python hik_osd_setup.py --remove <IP> <用户> <密码>

或登录摄像头 Web，在「字符叠加」里删掉那一条。
删除后摄像头回到出厂状态，不影响其它功能。


九、适用范围

已验证：海康 DS-2PT1A40MZ-DE，固件 V5.8.10
其它海康型号：先跑「检查」，看摄像头是否支持 CreateOSD。
  支持 → 通常可用（token 编号需为 102）
  不支持 → 工具会报错，需要换方案

大华 / 普天视：本工具不适用（那两类摄像头的 OSD 结构和命名不同，
主板的候选列表里已经有它们的 token）。
